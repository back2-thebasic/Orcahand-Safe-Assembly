# 2026-09-29 组员 taskgen 任务的 PPO 训练

环境：[niujiazhen/orca-agent-taskgen](https://github.com/niujiazhen/orca-agent-taskgen) @ `d2809a5` 生成的三个示例任务（v1 手，6 自由度运动学手腕，无机械臂）。
对环境的修改以补丁形式放在 `../taskgen_rl/patches/`（8 个 commit，在本地分支 `fix/rl-reward-exploits` 上，未推到组员仓库）。

PPO 设置沿用转方块任务：14 个并行环境 × 292 步，batch 1024，lr 1.5e-4，γ 0.995，target_kl 0.02，log_std 初值 −0.5、上限 0。
评估：确定性动作，100 个回合，复位 seed 0–99；关键结果用 seed 1000–1099 复核。

## 每一步修了什么、为什么

### 训练之前：两个会被 RL 利用的漏洞（`0001`）
- **抓住奖励按步发放。** 抓住后一直不放，整回合能拿约 2000 分，而完成任务只有 +100 然后回合结束。脚本控制器抓住后冻结得 1751 分，完成任务只得 707 分。改成势函数：抓住时 +2，松开时 −2。
- **放置任务不需要真的拿起来。** 原成功条件只要求「物体在目标区、速度慢、手已松开」，随机策略 150 回合里有 4 次把圆柱推进目标区就算成功。改为必须先在抓住状态下抬高 ≥5 cm。

### 抓起（`0002`）
- pickup_s0（原始奖励，20M 步）：0%。碰到物体之前没有任何奖励，唯一的稠密项是动作惩罚，策略学会了不动（std 0.54 → 0.05）。
- 加入接近奖励（指尖中心到物体距离的势函数，权重 50）后，pickup_reach_s0 在约 125 万步时成功率达到约 100%（75 万步时 84%）。

### 握拳（`0003`–`0006`），失败了 4 次
| run | 改动 | 结果 | 卡在哪 |
|---|---|---|---|
| fist_s0 | 原始 | 0% | 每完成一个阶段反而被扣分（−5.3/−4.0/−9.1），且策略看不到当前阶段 |
| fist_fix_s0 | 阶段切换时重置基准 + 阶段可观测 | 0% | 复位姿势就是第一个目标，但第一步之后才检查，零动作第一步误差已到 0.16 > 0.05，序列从未开始 |
| fist_stage_s0 | 复位即完成第一段 + 每段 +10 | 0% | 确定性动作离半握最近 0.085：绝对动作要每步精确输出 17 个数 |
| fist_rel_s0 | 手指改为相对动作（每步 ±0.15 半程） | 0% | 能到握拳，最后张开卡在 0.10–0.12，线性奖励在最后一段只值 0.6 |
| **fist_prec_s0/s1** | 距离奖励加高斯项（宽 = 2×容差） | **100%** | — |

| run | 改动 | 结果 | 卡在哪 |
|---|---|---|---|

## 需要组里讨论的问题

1. **成功的策略动作不真实。**
   - 抓起：0.28 s 内把方块往上甩到 28.8 cm（成功只需 5 cm）。
   - 放置：手指挑起圆柱 6.5 cm，带着横移约 5 cm 后在空中以约 1 m/s 松手，圆柱自己飞进目标区并倒下。
   - 握拳：手指动作正确，但手腕被随意转动（手腕 6 维与该任务的奖励无关）。
   这些都满足现有成功条件。要得到能上实体手的动作，需要：物体速度/加速度上限、松手时的高度和速度限制、放置后保持竖直、手腕运动惩罚（或手势任务锁住手腕）。
2. **放置只有 1/2 个 seed 成功**，seed 1 停在「抓住不动」这个局部最优。按转方块任务的规则（两个 seed 都要成立）还不能算解决。
3. **环境本身**：浮空的运动学手腕、无限大支撑平面，和实体手差距较大（组员 README 已说明是简化）。

## 复现

```bash
cd orca-agent-taskgen
git checkout -b fix/rl-reward-exploits d2809a5
git am ../Orcahand-Safe-Assembly/Orca_rl/taskgen_rl/patches/*.patch
.venv/bin/python -m pytest tests/test_rl_exploits.py -q       # 10 passed
.venv/bin/python rl/train_bundle.py --bundle examples/generated/handfist_v0 --name fist_prec_s0 --seed 0 --relative-hand 0.15 --timesteps 15_000_000
.venv/bin/python rl/train_bundle.py --bundle examples/generated/bluecylinderplace_v0 --name place_rel_s0 --seed 0 --timesteps 30_000_000
.venv/bin/python rl/evaluate_bundle.py --model runs_taskgen/place_rel_s0/final_model.zip --episodes 100
```

速度：M4 Mac 约 10,000 步/秒（30M 步约 50 分钟）；desktop（WSL，i9）约 4,000 步/秒。
