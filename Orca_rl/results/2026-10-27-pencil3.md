# 转笔任务：pencil3（3000 万步，立起算掉落 + 从停住处重开）

日期：2026-10-27 · M4 Mac，10 个环境，seed 0，模型在 `models/pencil3/`。在 pencil2 的基础上（`--pose-penalty 5e-4`）加了两项：

```
python -m orca_rl.pencil_train --name pencil3 --timesteps 30_000_000 --n-envs 10 --seed 0 \
    --pose-penalty 5e-4 --max-stand-deg 60 --stall-start-prob 0.5
```

- `--max-stand-deg 60`：铅笔倾斜超过 60° 就结束 episode，扣掉落惩罚 2。针对 pencil2 把铅笔立在指缝里停下。
- `--stall-start-prob 0.5`：一半的复位从之前某个 episode 第一次停住（在手上，1 秒内净转不到 10°）的状态继续。

用时 1 小时 08 分钟，约 7300 步/秒。仿真没有数值爆掉（830 个统计窗口全是 0）。结束时 `std` 0.31、`train/epochs_used` 3、`explained_variance` 0.99。

**结论先说：立起算掉落起作用了——铅笔不再立起来，停下时是平放的（倾斜中位数 3°）、手是张开的——但策略还是转约 90° 就停，
只是换了第三个停靠位置：平放在张开的手上，朝向约 52°。** 停下之后它比前两个模型更常再推一下（第二个 10 秒里 17% 的 episode
多转超过 10°，pencil2 是 3%），但离连续转还很远。从停住处重开这一招的效果有限，原因见下面「为什么重开帮助不大」。

## 停在哪里

倾斜（第 10 秒，60 个 episode 里 51 个没掉也没立起）：中位数 3°，没有一个超过 45°，铅笔中心高度中位数 0.175 m。立在指缝里的停法完全没有了。

停下的朝向（模 180°，80 个 episode 里 70 个）：平均转了 87°，停止转动的时间中位数 3.4 s；45°–60° 一档 70 个里占 59 个，平均 52°，
集中程度 R = 0.95（pencil1 0.63、pencil2 0.83）；初始朝向和转角的相关系数 +0.41。

录像（复位 seed 7–9，没有放进仓库；`demo_videos/8_pencil_compare.mp4` 右下格是 pencil3）：开头手指弯曲把横放的铅笔推转过去，约 3 秒后铅笔斜放在手上，
四指伸直并且张开，之后基本不动。

三个模型停在三个不同的朝向（79°、18°、52°），每个模型推转的过程又都经过了另外两个模型的停靠朝向，
所以停不是因为某个朝向在几何上过不去；缺的是推完一次之后**再推一次**（手指回位、重新接触、再推）。

## 为什么重开帮助不大

观测里没有时间，从停住的状态重开在物理上和原 episode 接着往下跑完全一样（`pencil_checks.py` 验证了逐位相同）。
而 pencil1/2 每个 episode 本来就有约 75% 的时间停在那里：「停住之后的状态」从来不缺样本。重开只是把这部分经验从约 75% 提高到约 87%，
并且去掉了一部分「从头推 100°」的容易经验。真正缺的不是停住状态的样本，而是在那些状态里试出「再推一次」的探索。
这一点在提出方案时（`results/2026-10-26-pencil2.md` 第 2 条）想得不够清楚。

## 下一步可以试的

1. **接着训。** 曲线到 3000 万步还在涨，`--resume runs/pencil3/final_model.zip` 再训 3000 万步，成本最低，也能回答「是不是只差时间」。
2. **加大探索。** `std` 从 0.5 降到 0.31。可以试 `--ent-coef`，或者在停住的状态上用更大的动作噪声。
3. **换奖励结构。** 比如像方块任务那样给一个不断前移的目标朝向（目标写进观测），让「已经推过一次」在状态里看得出来。
   这要改环境和检查，工作量最大。
4. 任何结论都还需要第二个 seed。

## 续训到 6000 万步（模型在 `models/pencil3_60m/`）

```
python -m orca_rl.pencil_train --name pencil3_60m --resume runs/pencil3/final_model.zip --timesteps 30_000_000 \
    --n-envs 10 --seed 0 --pose-penalty 5e-4 --max-stand-deg 60 --stall-start-prob 0.5
```

参数不变，从 3000 万步的模型和观测统计接着训，用时 54 分钟。仿真没有数值爆掉（815 个窗口全是 0）。结束时 `std` 0.27。
停住状态的缓冲区不随模型保存，续训开头重新积累。

**结论：多训的 3000 万步让第一下推得更远、更久，但没有学会再推一次；同时找到了第四个停靠位置：
把铅笔沉进指缝，低于「在手上」的高度线（0.13 m）。** 那里不计分、不扣分，也还没算掉落（0.12 m）。
按续训前定的标准（20 秒 episode 的后 10 秒平均多转 30° 以上、超过 40% 的 episode 还在转），答案是否定的。

训练曲线（每 1000 万步内各窗口的中位数）：正常开局的圈数 0.20（2000 万–3000 万）→ 0.23 → 0.24 → 0.28（5000 万–6000 万），
重开 0.09 → 0.08 → 0.10 → 0.13；立起结束的比例从 3000 万步时的 7% 升到最后的 17%–18%。

7.5–10 秒仍然只有 2°。停下的朝向从 52° 移到 68°（R = 0.93），还是一个固定终点。

## 四次训练的停法

| 模型 | 改了什么 | 停法 |
|---|---|---|
| pencil1 | — | 握拳夹死 |
| pencil2 | 姿态惩罚 | 立在指缝里（倾斜 > 45° 不计分） |
| pencil3（3000 万） | 立起 > 60° 算掉落、从停住处重开 | 平放在张开的手上不动 |
| pencil3（6000 万） | 多训 3000 万步 | 沉进指缝，低于「在手上」高度线（不计分） |

每堵住一个零成本的停靠位置，策略就找下一个；「停」本身（铅笔平放在手上不动）始终是零成本、零风险的。
继续用这套奖励往上堆训练时间不太可能得到连续转动，需要改方法。
