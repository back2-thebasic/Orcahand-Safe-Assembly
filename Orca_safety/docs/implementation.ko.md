# 현재 구현과 검증

[English](implementation.md) | [中文](implementation.zh.md) | [한국어](implementation.ko.md)

안전 계층은 v1 오른손 MuJoCo 시뮬레이션을 대상으로 합니다. 인터페이스 규약은 [baseline.ko.md](baseline.ko.md), 설치와 실행 방법은 [메인 README](../README.ko.md)와 [scripts README](../scripts/README.ko.md)를 참고하세요.

## Safety Layer 구현

- **충돌 거리와 CBF**: Pinocchio/FCL이 설정된 108개 링크 쌍을 검사합니다. 기본 안전 간격은 5 mm이며, 거리가 15 mm 미만이면 제약이 활성화됩니다. 먼 쌍은 보수적인 AABB 거리 하한으로 선별하고, 가까운 쌍은 거리 기울기를 계산합니다.
- **QP 필터링**: OSQP는 CBF 제약, 관절 범위와 스텝당 움직임 제한을 만족하면서 원래 목표값을 최대한 유지합니다.
- **Nonlinear Command Validation and Fallback**: 후보 목표의 거리를 다시 검사합니다. 부적합하면 움직임을 최대 8회 절반으로 줄이며, 각 시도에서 모든 제약을 확인합니다. 적합한 후보가 없거나 솔버가 실패하면 마지막으로 검증된 목표를 재사용합니다.
- **선택적 모드와 로그**: `--collision-safety`는 필터링을 활성화하고, `--collision-monitor`는 모니터링만 수행합니다. JSONL 로그에는 입력, 출력, 실제 상태, 거리와 개입 정보가 저장됩니다.

## 이후 변경 사항

- **시작 상태 동기화 수정**: retargeter 보정을 기다리는 동안 MuJoCo의 실제 reset 자세를 유지하여 core neutral 자세와의 불일치를 방지합니다. 후보 움직임을 점진적으로 줄여, 반복적인 검증 실패로 이전 목표만 계속 유지하던 문제를 완화합니다. `nonlinear_backtracking_steps=0`으로 축소 시도를 끌 수 있습니다.
- **선택적 웹캠 녹화**: `--record-video`는 사람 손 영상과 시간 메타데이터를 저장합니다. 원본 영상의 시간 기준으로 재생 구간을 선택할 수 있습니다.
- **영상 비교**: `replay_video.py`는 동일한 nominal 입력으로 OFF, ON 및 나란히 비교하는 영상을 생성합니다. 구간 선택, 카메라 조정과 느린 재생을 지원합니다.
- **대화형 재생**: `replay_viewer.py`는 MuJoCo 창에서 OFF/ON을 각각 관찰할 수 있도록 자유 시점, 일시 정지와 프레임 단위 이동을 지원합니다. 궤적을 먼저 계산하므로 표시 속도는 안전 제어 스텝을 바꾸지 않습니다.

## 검증과 데모

- **자동화 테스트**: 최근 기록된 실행에서 26개 테스트가 통과했습니다. 기하, QP, 실패 시 대체 동작, 시작 상태 동기화와 재생 이력을 검사합니다. 실행 방법은 [tests README](../tests/README.ko.md)를 참고하세요.
- **정적 기하 검사**: [passive/](../output/passive/)에 자세, 거리와 기울기 검증 결과가 있습니다.
- **기존 데이터 실험**: [7개 합성 동작 비교](../output/comparison/README.ko.md)와 [retarget 재생 요약](../output/retarget-comparison/summary.json)에 OFF/ON 결과가 있습니다.
- **시각적 데모**: [4개 데모](../output/video/demo_video/README.ko.md)는 실제 사람에게서 수집한 동작과 합성 동작인 검지–중지 교차를 포함합니다.

## 현재 한계

- 설정된 충돌 쌍만 검사합니다. 같은 손가락 내부의 쌍과 일부 구조적 접촉은 제외되며, 5 mm 간격은 손끝 접촉도 제한합니다.
- 목표 검증과 제어 스텝별 샘플링은 전체 연속 궤적의 안전을 보장하지 않습니다. 실제 동적 움직임에는 여전히 오버슈트가 발생할 수 있습니다.
- 메시 거리 조회, 기울기 계산과 단계 축소 시도는 지연을 증가시킵니다. 안정적인 실시간 원격 조작 성능은 아직 입증되지 않았습니다.
- OFF에서도 MuJoCo의 제어 제한과 접촉력이 유지되므로 교차 목표가 접촉과 압박으로 나타날 수 있습니다. ON에서 위험한 목표를 끝까지 수행하지 못하는 것은 의도된 개입입니다.
- 결과는 시뮬레이션에만 해당하며 실제 로봇 손의 안전은 검증하지 않았습니다. 안전 모듈의 테스트 통과는 다른 프로젝트의 모든 테스트가 통과했다는 뜻이 아닙니다.
