# Experimental Outputs and Replay Data

[English](README.md) | [中文](README.zh.md) | [한국어](README.ko.md)

This directory contains Safety Layer experiment results, motion inputs, teleoperation recordings, and demo videos. See [scripts/README.md](../scripts/README.md) for usage.

## Directory

```text
output/
├── comparison/          OFF/ON logs, summaries, and plots for seven synthetic motions
├── video/
│   ├── demo_video/      Four OFF/ON motion video demos
│   └── camera/          Webcam recordings and timing alignment files
├── passive/             Five static poses, poses.json, distance/gradient verification
├── replay/              Replay inputs generated by retargeting synthetic landmarks
├── retarget-comparison/ OFF/ON logs and summaries for those replay inputs
├── synthetic/           Directly generated motions, including index/middle crossing
├── teleop/              Live targets, measured states, and safety logs
└── environment/         Python/package versions used for historical experiments
```

## Reading Guide

- [Four motion video demos](video/demo_video/README.md): visually compare OFF/ON behavior.
- [Seven synthetic-motion comparisons](comparison/README.md): collision, clearance violation, intervention, and runtime results.
- [Retarget replay summary](retarget-comparison/summary.json): OFF/ON results for synthetic landmarks processed by the original retargeter, not live recordings.

## Files

- **`.jsonl`**: per-step logs or synthetic motion inputs. Runtime logs generally start with `event=start` for configuration, joint order, and units, followed by `event=frame` records.
- **`.npy` / `.npz`**: NumPy target trajectories or landmark data. `summary.json` stores experiment summaries.
- **Webcam `.timing.json`**: maps source-video clip times to teleoperation logs; use with `--video-timing`.

Common log fields: `q_nominal` is the original target, `q_safe` is the filtered target, and `q_measured` is the actual post-step state. `min_distance_measured` is the post-step minimum clearance; `fallback` and `error` indicate fallback and its reason.

Angles are in rad and distances in m. Read array order from `joint_names`. Target-pose distances differ from actual motion distances; insufficient safety clearance does not necessarily mean a collision.
