# 검지–중지 교차: 합성 목표 동작

[中文](README.zh.md) | [English](README.md) | [한국어](README.ko.md)

`motion.jsonl`은 v1 오른손의 합성 nominal 입력입니다. 실제 사람 손의 retargeting 기록이 아니며 실행 결과는 포함하지 않습니다. `replay_viewer.py`와 `replay_video.py`에서 사용할 수 있고, OFF와 ON에 같은 파일을 입력합니다.

총 600개 제어 단계로, 단계당 0.01초이며 시뮬레이션 시간은 6초입니다.

- 0～1초: 다섯 손가락이 펼쳐진 모델 reset 자세를 유지합니다.
- 1～2.5초: 검지와 중지를 교차 목표 쪽으로 서서히 움직입니다.
- 2.5～3.5초: 교차 목표를 유지합니다.
- 3.5～5초: 펼친 자세로 서서히 돌아갑니다.
- 5～6초: 실제 움직임이 안정되도록 펼친 자세를 유지합니다.

검지와 중지의 외전 관절만 변경하고 다른 목표는 유지합니다. 교차 목표는 검지 abd=0.23 rad (약 13.18°), 중지 abd=−0.40 rad (약 −22.92°)이며, 부드러운 3차 보간을 사용합니다. 이 값은 모델 좌표계의 절대 각도이며 영점으로부터의 증분이 아닙니다.

목표는 관절 범위 안에 있지만 설정된 검지–중지 충돌 기하가 서로 겹칩니다. OFF도 MuJoCo의 제어 제한과 접촉 동역학을 유지하므로, 접촉력 때문에 손가락이 압박된 자세에서 멈추어 완전한 교차 목표를 달성하지 못할 수 있습니다. ON은 더 일찍 접근을 제한해야 하며 교차를 완료하지 않는 것이 예상된 개입입니다. 확대 및 회전으로 가까이 관찰하세요. 실제 동작은 재생 결과를 기준으로 판단합니다.

작업 공간 최상위 디렉터리에서 실행합니다.

```bash
orca_teleop/.venv/bin/mjpython Orca_safety/scripts/replay_viewer.py \
  Orca_safety/output/synthetic/index-middle-crossing/motion.jsonl \
  --mode OFF --view front --speed 0.5 --paused
```

OFF를 ON으로 바꾸면 안전층 효과를 볼 수 있습니다. macOS 대화형 창은 `mjpython`으로 실행해야 합니다. 스페이스는 재생/일시 정지, N/B는 한 단계 앞으로/뒤로, R은 처음으로 돌아갑니다. 마우스로 시점을 조절할 수 있습니다. 웹캠 영상이 없으므로 `--video-timing`은 필요하지 않으며, `--clip`은 합성 궤적 시간 기준입니다.

ON은 합성 목표에 현재 안전층을 다시 적용하며, 수동으로 작성한 회피 궤적이 아닙니다. 검사는 설정된 쌍과 샘플링 상태만 포함하며 임의의 연속 궤적이나 실제 로봇의 안전을 보장하지 않습니다. 이 입력은 시뮬레이션 데모용입니다.
