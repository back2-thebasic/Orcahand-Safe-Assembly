# Retargeting + Safety Layer Benchmark

[English](benchmark_report.en.md) | [中文](benchmark_report.md) | [한국어](benchmark_report.ko.md)

하드웨어 모델: v1 오른손; 안전층: orca_safety_v2

각 시나리오의 OFF와 ON은 동일한 nominal 궤적을 사용합니다.

ON은 실제 운영 안전 경로를 다시 실행합니다. OFF는 모니터링만 수행하며 MuJoCo의 목표 제한과 접촉 동역학은 유지합니다.

## 여섯 가지 지표 설명

N은 해당 시나리오에서 통계에 포함된 제어 프레임 수입니다. 처음 세 지표는 실행 후 실제 자세의 안전성을 평가하고, 동작 수정량은 목표의 변화를 평가합니다. fallback과 소요 시간은 실행 비용을 평가합니다.

### 1. 최소 실제 충돌 거리 (mm)

- **계산 방법**: 각 제어 단계 실행 후 설정된 충돌 쌍의 최소 거리를 측정하고, 전체 실행 중 최솟값을 취합니다: `min(min_distance_measured) × 1000`.
- **의미**: 동작 중 가장 위험한 순간의 실제 간격입니다. 설정된 안전 거리와 비교해야 합니다. 예를 들어 안전 거리가 5 mm이고 실제 최소 거리가 3 mm이면 안전 간격이 부족하지만, 반드시 충돌이 발생했다는 뜻은 아닙니다.
- **비교 방법**: ON이 간격을 안전 거리 부근 또는 그 이상으로 유지하는지 확인합니다. 간격이 커진 이유가 더 큰 동작 수정일 수도 있으므로 네 번째와 다섯 번째 지표를 함께 봐야 합니다. 형상이 겹칠 때의 거리를 신뢰할 수 있는 관통 깊이로 직접 해석해서는 안 됩니다.

### 2. 실제 충돌률 (%)

- **계산 방법**: `measured_collision=True인 프레임 수 / N × 100%`. 한 프레임에서 여러 충돌 쌍이 충돌해도 한 프레임으로 계산합니다.
- **의미**: 실행 중 샘플링된 프레임에서 충돌이 발생한 비율입니다. `12.5% (15/120)`는 120프레임 중 15프레임에서 충돌이 있었다는 뜻이며, 독립적인 충돌 사건이 15번 발생했다는 뜻은 아닙니다.
- **비교 방법**: 낮을수록 좋으며, OFF 대비 ON의 감소 폭을 확인합니다. 0%는 검사한 제어 프레임에서 충돌이 없었다는 뜻이며, 제어 단계 사이에도 충돌이 전혀 없었다는 보장은 아닙니다.

### 3. 안전 여유 위반율 (%)

- **계산 방법**: `실제 최소 거리가 설정된 safe_distance보다 엄격히 작은 프레임 수 / N × 100%`. 운영 로그의 `measured_margin_violation`을 사용합니다.
- **의미**: 손가락이 안전 완충 영역에 들어갔는지 확인합니다. 예를 들어 설정된 안전 거리가 5 mm이고 실제 간격이 2 mm이면 충돌하지 않았더라도 이미 위반입니다. 따라서 충돌률이 0이어도 안전 여유 위반율은 0이 아닐 수 있습니다.
- **비교 방법**: 낮을수록 좋습니다. 충돌률과 함께 확인하여 안전층이 접촉을 피하면서 필요한 간격도 유지하는지 판단합니다.

### 4. 평균 동작 수정량 (rad)

- **계산 방법**: 각 프레임에서 전체 17개 관절의 `||q_safe − q_nominal||₂`를 계산한 뒤 N프레임의 평균을 구합니다.
- **의미**: 안전층이 원래 목표를 얼마나 변경했는지 나타냅니다. 손 전체의 관절 벡터 차이이며, 단일 관절의 평균 오차나 실제 자세와 목표 사이의 추종 오차가 아닙니다.
- **비교 방법**: 안전 요구를 충족한다는 전제에서 값이 작을수록 원래 동작을 더 많이 보존합니다. OFF는 안전 필터링을 거치지 않으므로 값이 0이지만, 실제 자세는 MuJoCo의 제한과 접촉력에 영향을 받을 수 있습니다. 위험한 목표는 수정이 필요하므로 수정량이 크다는 이유만으로 ON의 효과가 나쁘다고 판단해서는 안 됩니다. 이 지표는 동작 완료 여부도 판단하지 않습니다.

### 5. Fallback 비율 (%)

- **계산 방법**: `fallback=True인 프레임 수 / N × 100%`.
- **의미**: 해당 프레임에서 모든 검사를 통과한 새 목표를 생성하지 못하여 이전에 검증된 안전 목표를 재사용한 경우입니다. QP 오류, 실행 불가능한 문제, 잔차 검사 실패, 최종 비선형 검증 실패 등이 fallback을 유발할 수 있습니다. 스텝을 줄여 적합한 목표를 찾은 경우는 fallback으로 계산하지 않습니다.
- **비교 방법**: 값이 낮으면 일반적으로 fallback에 덜 의존합니다. 충돌률은 낮지만 fallback 비율이 높다면 이전 목표를 유지하는 방식으로 주로 안전을 확보하는지 확인해야 합니다. Fallback은 보호 장치이며 실제 충돌을 뜻하지 않습니다. OFF의 0은 필터링을 사용하지 않은 결과일 뿐, OFF가 더 신뢰할 만하다는 뜻은 아닙니다.

### 6. 안전층 p95 소요 시간 (ms)

- **계산 방법**: ON의 프레임별 운영 계측값 `total_safety_time_ms`에서 95번째 백분위수를 구하며, NumPy의 기본 선형 보간을 사용합니다.
- **의미**: 통계에 포함된 프레임 중 약 95%의 안전 계산 시간이 이 값 이하입니다. filter 내부의 거리, 기울기, QP, 검증 및 fallback 계산을 포함합니다. 시뮬레이션 진행, 실행 후 측정, 로그 기록, retargeting 및 큐 대기 시간은 포함하지 않습니다.
- **비교 방법**: 낮을수록 좋으며 제어 주기와 비교해야 합니다. 예를 들어 제어 주기가 10 ms이고 p95가 50 ms이면 안전 계산이 느린 프레임은 한 주기의 시간 예산을 초과하므로 100 Hz 실시간 요구를 충족한다고 볼 수 없습니다. OFF는 필터링을 실행하지 않으므로 N/A로 표시합니다. p95는 최대 소요 시간도, 전체 원격 조작 지연도 아닙니다.

처음 세 지표로 안전 효과를 판단하고, 동작 수정량과 fallback으로 동작 비용을 판단하며, p95로 계산 시간 예산을 판단합니다. 이 실험은 오프라인 시뮬레이션이므로 계산이 느려도 고정된 시뮬레이션 시간 간격으로 진행하며 입력 프레임을 건너뛰지 않습니다.

## 일부 동작의 최소 거리가 같은 이유

`open`, `fist`, `spread`, `assembly_like_synthetic`의 OFF/ON 전체 실행 최소 거리는 모두 6.228 mm입니다. 그러나 서로 다른 동작이며, 실행 내내 거리가 같은 것은 아닙니다.

- open (펼친 손 유지): 모델 reset 자세를 유지합니다. 네 손가락의 MCP/PIP 굽힘 목표는 0이며, 검지·중지·약지·소지의 ABD 목표는 각각 −0.4, 0, 0.17, 0.52333 rad입니다. 여기서 펼친 손은 모델의 초기 자세이며, 손가락을 최대한 벌린 자세를 뜻하지 않습니다
- spread (더 벌리기): 펼친 손의 굽힘 목표를 유지하고 네 손가락 ABD 목표를 −0.8, −0.3, 0.5, 0.9 rad로 변경합니다. 손 펼치기 → 벌림 목표 → 손 펼치기를 실행합니다. open과 달리 손가락의 좌우 벌림 정도를 바꿉니다
- fist (네 손가락 동시 굽힘): 네 손가락의 MCP/PIP 목표를 모두 1.2 rad로 설정하고 손 펼치기 → 굽힘 목표 → 손 펼치기를 실행합니다. 엄지와 네 손가락 ABD 목표는 그대로이므로, 엄지를 접는 완전한 주먹이 아닌 단순화된 네 손가락 굽힘입니다
- assembly_like_synthetic (합성 잡기): MCP/PIP 목표를 검지 0.4/0.8, 중지 0.45/0.8, 약지 0.5/0.9, 소지 0.6/1.0 rad로 설정합니다. 손 펼치기 → 굽힌 잡기 목표 → 손 펼치기를 실행합니다. 손가락마다 굽힘 정도가 다르고 엄지와 ABD 목표는 그대로입니다


**공통 시작 자세가 전체 최소값을 결정합니다.** 여덟 개의 프레임 로그를 확인한 결과, 모두 첫 제어 단계 실행 후 공통으로 펼친 손 자세인 프레임 0에서 최소값이 나타납니다. 정확한 값은 6.228385962 mm이며 최근접 쌍은 `right_middle_mp__right_ring_mp`입니다. 이 지표는 모든 집계 프레임과 설정된 충돌 쌍의 최솟값을 취하므로 이후 간격이 커져도 전체 최소값은 바뀌지 않습니다. 예를 들어 spread의 프레임 60 실제 최소 거리는 약 7.677 mm이지만 전체 최소값은 6.228 mm입니다

**네 손가락 굽힘은 이 두 mp 부품의 상대 위치를 직접 바꾸지 않습니다.** URDF 구조는 손바닥 → ABD → mp 부품 → MCP → 이후 손가락 분절입니다. 중지와 약지의 mp 부품은 MCP 굽힘 관절보다 앞에 있습니다. 따라서 fist와 assembly_like_synthetic에서 이후 분절이 움직여도 기존 mp 쌍이 손 전체의 최소 거리를 결정할 수 있습니다. ABD를 고정하고 네 손가락 MCP/PIP를 0, 0.3, 0.6, 0.9, 1.2 rad로 바꾸어 정적으로 재계산한 결과 이 쌍의 거리는 모두 6.227600869 mm였습니다. 정적 목표와 실행 후 실제 자세는 서로 다른 측정이며 동역학 때문에 약간의 차이가 날 수 있습니다

**다른 거리는 실제로 변합니다.** 정적 open과 fist 목표를 비교하면 중지/약지 ip 부품 간 거리는 23.727 mm에서 6.800 mm로, 검지 ip 부품과 손바닥 거리는 46.502 mm에서 32.198 mm로 감소합니다. 생성 궤적과 저장된 입력이 프레임별로 일치하며, fist 유지 구간의 실제 네 손가락 MCP/PIP도 약 1.2 rad에 도달한 것을 확인했습니다. 입력을 중복 사용했거나 굽힘을 실행하지 않은 문제는 발견하지 못했습니다. 전체 최소 거리가 같다고 동작이 같은 것은 아니며, 이 지표만으로 동작 구간의 기하 변화를 판단할 수 없습니다
